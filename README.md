# 🌸 Shubh Vivah - Indian Wedding E-Invite Website

An interactive, responsive, festive, and bootstrapped Indian Wedding Invitation web application designed for laptops, tablets, and smartphones.

---

## 🌟 Theme & Aesthetic

- **Color Palette**: Sophisticated Indian Wedding Pastel Theme:
  - **Warm Linen Beige** (`#FBF8F4`, `#F5EFE6`)
  - **Dusty Mauve** (`#8F5577`, `#6E3A5A`, `#F4EBF1`)
  - **Powder Blue** (`#52829F`, `#A3C4D7`, `#EDF4F8`)
  - **Champagne Gold Accents** (`#C5A059`, `#D8BC7E`)
- **Visuals**: High-resolution pastel couple portrait and official photo of Hotel HR Greens, Indore.

---

## 📅 Wedding Timeline (Single Container Format)

As requested, all events are beautifully displayed in a **single, unified Timeline paper container** matching modern luxury wedding stationery:
- Continuous vertical axis with solid round node dots.
- Left side: Hand-crafted pastel wedding illustrations (Rings, Engagement Ring & Music, Haldi flowers, Tiered Cake).
- Right side: Bold uppercase Time, Ceremony Name, Details, Venue, Attire / Bana, and "Add to Calendar" buttons.
